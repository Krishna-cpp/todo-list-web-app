# To-Do List Web Application

## Overview
A simple task management web application built to practice frontend structure, user interaction handling, and dynamic task updates.

## Features
- Add new tasks
- Mark tasks as completed
- Remove tasks from list
- Dynamic UI updates for task state
- Clean layout for usability

## Tech Stack
HTML, CSS, JavaScript

## How to Run
1. Clone the repository
2. Open the project folder
3. Run index.html in your browser

## Learning Outcome
This project helped me understand DOM manipulation, event handling, and how small web apps manage user-driven state changes.
